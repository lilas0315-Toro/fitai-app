# FORM — 筋肥大トレーニング記録

週3回・1回約45分の筋肥大トレーニング向け、iPhone Safari対応の個人用アプリです。栄養・食事管理はありません。

## 主な機能

- 週3回の全身A/B/Cメニュー。各回6種目を基本に、種目を自由に追加・削除して7種目以上にも変更可能
- 追加した種目構成は端末に保存。ワークアウト開始後も種目を追加、削除、入れ替え
- セットごとの重量、回数、RIR、完了状態を記録。前回の記録から重量・回数を引き継ぎ
- 1秒ごとに更新する経過時間、種目ごとの休憩カウントダウン、休憩終了・15秒延長、一時停止／再開
- 種目の入れ替え、ワークアウト途中の自動保存
- 142種目のライブラリ。部位・器具・名前で検索
- 種目詳細から動作確認へ移動。基本メニューの種目は個別ページへ、それ以外も対象部位・器具の動画一覧へ案内（公開元を別タブで開き、動画を無断転載しない）
- 前面・背面の筋肉マップから関連種目を開き、種目詳細から対象筋をマップで確認
- 週の回数・負荷・筋肉別主働セット数・種目別の最高重量を振り返り
- JSONバックアップの書き出し・読み込み

## iPhoneで利用する

`index.html`を直接開くと画面の確認はできますが、PWAやオフライン機能は動きません。ホーム画面に追加して使う場合はHTTPSで公開し、iPhoneのSafariで公開URLを開いて **共有 → ホーム画面に追加** を選んでください。

GitHub Pagesで公開する場合は、ZIPを解凍して中のファイルと`icons`フォルダをリポジトリのルートにアップロードし、Settings → Pagesで公開します。公開方法はGitHub Pagesに限りません。

## 保存とバックアップ

トレーニング記録はIndexedDBを使ってこのブラウザ内に保存します。アカウントやクラウド同期はありません。Safariのサイトデータを消去したり、ストレージ不足でiOSがサイトデータを削除したりすると、記録を失うことがあります。**設定・バックアップ**から定期的にJSONを書き出してください。プライベートブラウズは継続保存には使わないでください。

Service Workerは初回オンライン表示後にアプリの基本ファイルを保存します。オフラインでは画面を開けますが、端末変更の同期はしません。

フォームの目安は一般的なトレーニング情報です。痛みが出る場合は運動を中止してください。重量や種目は自分の状態に合わせて調整してください。
